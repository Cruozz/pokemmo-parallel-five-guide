# 平行五通攻略工作台

这是一个离线可运行的 PokeMMO 平行五通攻略工作台。内容依据 `平行通关流程（暂定）` 整理，包含合众、关东、城都、丰缘、神奥五地区地图、26 个流程阶段、完整的跨地区轮换顺序、路线节点、逐步剧情、必打 NPC 编号、道馆打法、队伍配置和关键道具。

## 使用

双击 `start.cmd`。如果电脑有 Python，程序会启动本地页面并打开浏览器；如果没有 Python，也可以直接双击 `index.html` 使用。

最新版压缩包：[平行五通攻略工作台 v6](release/平行五通攻略工作台-v6.zip)

## 交互

- 左侧阶段导航：切换平行通关阶段。
- 首页“实际平行轮换顺序”：查看每一段打到哪里、下一站转去哪个地区，以及飞翔/轮换解锁点。
- 地图节点：点击节点同步右侧动作清单。
- “逐步执行攻略”：按原文拆分每一段的出发点、剧情触发、必打 NPC、可跳过战斗、技能/道具和下一步转场。
- 地图工具：放大、缩小、还原视图。
- 顶部搜索：搜索城市、道路、道馆、道具或战斗提示。
- 打印当前阶段：生成适合打印的当前阶段攻略页。
