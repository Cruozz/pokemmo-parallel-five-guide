# 平行五通攻略工作台

这是一个离线可运行的 PokeMMO 平行五通攻略工作台。内容依据 `平行通关流程（暂定）` 整理，包含合众、关东、城都、丰缘、神奥五地区地图、26 个流程阶段、完整的跨地区轮换顺序、路线节点、逐步剧情、必打 NPC 编号、道馆流程、关键剧情配图和关键道具。

## 使用

**GitHub 接续编辑（2026-10-10）**：最新内容已备份，继续编辑位置为左侧第 **19** 阶段 **关东 7**。下载 [继续编辑包](release/平行五通攻略-继续编辑-2026-10-10.zip)，解压后打开 `平行五通攻略.exe`，点击 **编辑流程 → 导入备份**，选择压缩包内的 `平行五通-攻略备份-2026-10-10.json`。导入后打开“关东 7”，即可接着修改摘要、步骤和图片。修改仍保存在这台电脑本机；回传 GitHub 前需要重新导出备份。

最新 JSON 也单独保存在 [backups/latest.json](backups/latest.json)，同目录保留带日期的原始导出副本和校验信息。它们包含 26 个阶段、132 个步骤和已编辑的摘要、图片及标注。备份校验：`node scripts/check-saved-backup.cjs`。这是攻略内容的接续；勾选的通关完成记录仍由各设备独立保存。

之前的手机同步网站暂不使用，本次接续通过 GitHub 下载程序与备份完成。

**Windows 程序版**：双击 `release/平行五通攻略.exe`，独立窗口打开攻略，图片已内置，使用时不需要 Python、Node.js 或攻略文件夹。程序为 Windows 10／11 的 64 位版本，需要 .NET Framework 4.8 及 Microsoft Edge WebView2 运行时；当前电脑已有这些组件。若另一台电脑缺少 WebView2，程序会提示打开[微软官方下载页](https://developer.microsoft.com/microsoft-edge/webview2/)。

程序版保留文字、步骤顺序、图片编辑及备份功能。编辑和完成进度保存在 `%LOCALAPPDATA%\PokeMMOParallelFiveGuide\profile`，exe 移动或更新后仍使用同一份数据。关闭窗口时会等待已经应用的修改保存完成；表单里尚未点击“保存这一步”的修改仍不属于已应用内容。

**从网页版迁移**：在原来的浏览器中点击“编辑流程 → 导出备份”，下载 JSON；再在 exe 中点击“编辑流程 → 导入备份”。新版窗口与原浏览器分别保存数据。内容备份包含上传图片，通关完成进度不包含在内容备份中。

exe 资源首次启动时解包到 `%LOCALAPPDATA%\PokeMMOParallelFiveGuide\content`，用户编辑数据单独保存在 `profile`。如果需要换电脑，请在程序中导出备份，复制 exe 与备份后再导入。程序内查阅攻略和编辑支持离线，打开资料来源与视频链接需要联网。

**网页版**：

双击 `start.cmd`。如果电脑有 Python，程序会启动本地页面并打开浏览器；如果没有 Python，也可以直接双击 `index.html` 使用。

历史压缩包：[平行五通攻略工作台 v8](release/平行五通攻略工作台-v8.zip)（不包含本次路线图与页面整理，请使用仓库根目录的 `index.html`）

## 交互

- 顶部“编辑流程”：在原攻略页面修改文字、配图与步骤顺序，操作见下方说明。
- 左侧阶段导航：切换平行通关阶段。
- 首页“实际平行轮换顺序”：查看每一段打到哪里、下一站转去哪个地区，以及飞翔/轮换解锁点。
- 地图节点：点击节点同步右侧动作清单。
- “逐步执行攻略”：每一步都有对应地图，并按场景配入原文截图；入口、目标、道馆和剧情动作在同一步查看。
- 点击全图：放大、缩小、适合窗口、隐藏标注；点击编号查看该位置的动作，放大后可滚动寻找区域。
- 分层地图：楼层较多时展开“其余楼层／区域全图”。岩山隧道和四地区冠军之路保留社区路线与楼梯编号，城都使用心金／魂银自己的地图。
- 步骤配图：场景截图和地图直接显示在对应步骤中，保留用户编辑、上传与标注的图片。原文图片素材保留在本地文件夹，供编辑时使用。
- 本机进度：可勾选已完成步骤、设置当前位置；进度自动保存在当前浏览器，刷新后仍会保留。
- 地图工具：放大、缩小、还原视图。
- 顶部搜索：搜索城市、道路、道馆、道具或战斗提示。
- 打印当前阶段：生成适合打印的当前阶段攻略页。

## 自己编辑攻略（2026-10-07）

保留原来的阶段导航、线性执行清单和图解。点击顶部 **编辑流程**，进入当前阶段；每一步旁边会出现编辑操作。

1. **编辑文字与图片**：修改地点标题、具体动作、NPC／战斗提示和获得内容／完成条件。支持多行文字，保存后直接显示在原步骤中。
2. **上移／下移**：调整步骤顺序，文字、场景图、地图和完成标记一起移动。**在下方加一步** 或阶段中的 **新增步骤** 可插入自定义流程。
3. **图片展示顺序**：在“编辑文字与图片”中，拖动图片左侧的 ↕，或点击“前移／后移”。场景截图和地图可交叉排列，标题、说明及标注随图片一起移动。PNG、JPG、WebP 每张最多 5 MB。
4. **图片标注**：点击“画线／文字”或阅读卡片上的“编辑图片标注”，可画自由线路、折线路线、直线、箭头、多行文字和顺序编号。折线依次点击拐点，双击或 Enter 完成。选择“文字”后直接点击图片输入：Enter 完成、Shift+Enter 换行、Esc 取消；双击已有文字可就地修改，或选中后点“编辑选中文字”。选择“① 顺序编号”后连续点击图片，自动按①、②、③递增；支持 1—99，也可指定或修改编号及大小。“选择／移动”可拖动已有标注、用方向键微调、修改颜色／线宽／字号或删除，支持撤销重做。图太大时可放大并滚动查看。点击“应用标注”，再点击“保存这一步”。正在图片内输入的文字会在应用时一并确认。原图与标注分别保留，重新打开后仍能编辑；取消不保存本次标注。
5. **对应地图**：选择原有地图素材，或上传自己的图片。更换图片会清除这张图片的自定义标注，新上传地图也不继承旧地图的地点和路线标记。步骤与原地区总览的关联可在“对应的总览地点”中调整。
6. **编辑阶段说明**：修改阶段名称、简介、完成条件、通路检查和转区提示。**还原本阶段** 恢复原始内容；删除、还原、导入等内容操作均可在当前页面撤销（最多 12 次）。
7. **结束编辑**：隐藏编辑工具，恢复阅读模式。

点击表单中的“保存这一步”才应用文字与图片修改；“取消”或 Escape 放弃表单中尚未保存的内容。步骤排序、删除等操作会立即应用。应用后自动保存到当前浏览器，也可点击“保存到本机”确认。刷新后恢复编辑内容，旧的完成进度会按原步骤迁移。

**地图原有编号说明（1.2.2）**：进入“编辑流程”，点击地图下方的“编辑编号说明”；也可在“编辑文字与图片 → 对应地图”中展开“地图编号说明”。可以修改图上编号、节点名称与详细动作，上移／下移调整说明顺序，取消“显示此节点”隐藏其预设编号和说明，“全部隐藏”隐藏这张图的所有预设节点。编号不会随排序自动改变，可自行填写；“恢复原有编号说明”只还原当前步骤这张地图的节点。点击“保存这一步”后应用并保存，导出备份包含这些修改。它不改变其他步骤中的同一张地图，也不改变手绘线路、文字或顺序编号；手绘内容继续使用“编辑图片标注”。底部地图来源仍作为资料出处保留。

**地图节点摘要（1.2.3）**：进入“编辑流程”，点击“地图节点摘要”中各地点右侧的“编辑摘要”。填写这个地点的大概流程，可分行写顺序；点击“保存摘要”后直接显示在节点列表，原有详细步骤跳转继续保留。摘要单独保存，修改它不会改写详细步骤；未自定义时从当前关联步骤的首句生成简短概括。“恢复自动摘要”后保存，可重新跟随步骤内容。留空并保存可隐藏概括文字。摘要支持撤销、本机自动保存和备份导入导出，新版 exe 保留原本机编辑内容。

**导出备份** 包含所有编辑的阶段、节点摘要、步骤、文字、图片排列顺序、上传图片以及可继续编辑的图片标注。旧版备份可直接导入，新版 exe 沿用原本机数据。换浏览器、端口或电脑前请导出；在另一处打开同一份攻略文件夹，再用 **导入备份** 恢复。原素材由文件夹提供，因此移动时请保留整个文件夹。通关进度单独保存在当前浏览器，内容备份不包含进度。清除浏览器数据会清除本机编辑内容；保存失败时页面会提示导出备份。

编辑内容保存在浏览器中，不会自动改写仓库原始攻略文件，也不会同步到 GitHub。旧交互地图模板文件保留在 `interactive-map/`，主页面已移除入口。

编辑检查：`node scripts/check-guide-editor.cjs`。检查步骤和图片排序、增删、图文关联、旧进度及旧备份迁移、标注备份、空阶段、导入校验、SVG 文字转义和上传地图不继承原标记。2026-10-09 浏览器实际检查通过拖动图片手柄、跨类型排序、画线与箭头、中文文字、移动、撤销重做、取消、重新加载、截图放大及导出备份再导入。

1.2 版还检查编号连续放置、指定编号即时修改、编号微调与撤销、图片内中文输入、Shift+Enter 换行、Enter 完成、双击修改、Esc 保留原文字、空文字保护，以及尚在输入时点击“应用标注”。实际导出并重新导入备份后，编号和多行文字均保留；旧版线路及箭头标注继续兼容。

Windows 打包源码在 `desktop-app/`；在仓库目录的 PowerShell 中执行 `./scripts/build-desktop.ps1` 可重新构建。构建时使用 Windows 自带 C# 编译器，下载微软官方 NuGet WebView2 SDK 并检查固定 SHA-256 与微软签名。exe 内包含网页文件、所有本地素材及所需 SDK DLL，构建记录保存在 `release/平行五通攻略-build.json`。

打包与关闭保存协议检查：`node scripts/check-desktop.cjs`。需要先构建 exe；执行 `release/平行五通攻略.exe --extract-only desktop-app/.build/extracted-content-path.txt` 会仅核对并解包内置资源，不打开编辑窗口，也不改用户编辑数据。原始图文检查与编辑检查继续适用。窗口截图工具当前未能捕获程序画面，未完成 exe 内的图片上传与文件导出点击验证；实际启动、攻略加载和全部内置文件校验已通过。
