# 合众交互地图模板

双击本目录的 `index.html`，或在原攻略左侧点击“交互地图模板”。模板已经配入 51 张合众城市、道路、道馆与分层图，以及一张地区总览。

## 看攻略

先看三曜市示例：学校 → 道馆 → 研究所领取居合斩 → 梦之遗迹 → 返回研究所交接。

点击图上的地点，右侧显示动作及图片。点击图片可放大，关联的内部地图可以继续打开；“返回上张地图”回到原地点。“完成，前往下一步”记录进度并切换下一个动作。研究所的第 3 和第 5 步共用同一地点，地图显示 `3·5`，下方分别显示两次到访。

学校示例采用黑／白共用的学校内部全图，附与黑连对战的动作说明。这张图不是 PokeMMO 对战实景。原文 `image9.png` 实际为学校入口外景，已纠正原攻略图注。你可以上传自己的内部对战截图替换示例图。

## 编辑地图

1. 切到“编辑地图”，从地图库选择地图；也可以“添加自己的地图”并修改地图名称。
2. 点击“添加标记”，在图上点正确的位置。
3. 填写地点名、动作标题、具体动作、节点类型，选择配图或上传截图；可关联一张内部地图。
4. 点击“保存节点”。“重新定位”可在图上点新位置，也可直接输入横向、纵向百分比。
5. 用“上移一步／下移一步”调整顺序。“新增返回步骤”用于之后再次到访同一地点。
6. “画路线”模式中逐个点击实际道路拐点，再点“完成绘制”；绘制时可撤销最后一个拐点。程序不会把任务顺序自动当作行走道路。
7. “撤销”可以恢复本次页面打开后的最近修改；删除步骤也能撤销。“预览这个节点”切回阅读模式检查结果。

## 保存与备份

保存节点、调整顺序、添加地图等修改会自动保存到当前浏览器；也可以点击“保存草稿”。刷新会恢复已保存草稿及编辑位置。它使用独立的浏览器存储，不改原攻略的完成记录。

“导出”打开备份窗口，再点击“下载备份文件”。若浏览器不能下载，可展开“复制备份内容”，保存为 `.json` 文件。“导入”读取该备份；导入后可用撤销恢复导入前的草稿。

上传的地图和截图包含在 JSON 备份里，单张支持 PNG、JPG 或 WebP，最大 5 MB。预置素材仍引用工程里的 `assets`；换电脑时请复制整个攻略文件夹，并携带 JSON 备份。不同浏览器、文件打开方式和本地网址之间的草稿互不共享，需要通过导出／导入转移。

本次示例只预设了三曜市、鹿子镇与 2 号路的节点；其余地图供你自行标注。学校、道馆等内部图的具体 NPC 位置也可自行补充，模板不将未经核实的 NPC 位置标成必打。

## 素材与维护

已有地图及原文截图复用原工程，来源见原工程的素材说明。新增学校内部图来自 [Bulbagarden Archives](https://archives.bulbagarden.net/wiki/File:Striaton_Trainers_School_interior_BWB2W2.png)，原始图片保持不变，说明及下载地址保存在 `assets/school-source.json`；权利属于游戏权利人及原作者。

`demo-data.js` 是初始模板，实际编辑结果保存在浏览器中。`core.js` 处理节点、重复到访和导入校验，`template.js` 处理交互。检查命令：`node scripts/check-interactive-map.cjs`。`scripts/build-interactive-map-demo.cjs` 从原素材重建初始模板，不会覆盖浏览器中已保存的草稿。
